    How it works

    Three cheap steps, then one check.

    1. 01

      Scan

      Quantize one unit at a time to INT8 while the rest stay FP16 and measure the accuracy drop. Eleven evaluations.

    2. 02

      Score

      Rank units by latency saved per accuracy point lost, using per-unit timings measured on the target GPU at the target batch size.

    3. 03

      Flip

      Starting from all-FP16, switch units to INT8 in rank order and back off any flip that would exceed the budget.

    Every selection is compared against exhaustive search over all 1,024 configurations. Accuracies are measured on a validation split; test-set numbers are reported only for the final choice.
